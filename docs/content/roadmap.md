# Roadmap

:::warning[Planned, subject to change]
Everything on this page is a target, not a commitment. Quarters, scope, and treasury figures will move as the product does.
:::

| Quarter | Theme | Planned work | Target treasury TVL |
|---|---|---|---|
| Q1 | Foundation | Mainnet migration, payment rail activated, first 50 paid debates | $5K |
| Q2 | Growth | New specialist agents (Legal, Tokenomics), 2-3 accelerator and incubator partnerships | $50K |
| Q3 | Monetization depth | Subscription tier for founders and VCs, public API so other platforms can embed The Council | $200K |
| Q4 | Ecosystem standard | Become the standard due-diligence layer for BNB Chain launchpads, expand to Base and Arbitrum | $500K–$1M |

## How to read the targets

Treasury TVL is the balance held in the treasury vault, which accrues from debate fees. It is used as the growth metric because it is directly verifiable on-chain. See [Business Model](./business-model.md).

## What is live today

The debate engine, the on-chain thread registry, and the pay-per-debate payment rail run on BNB Chain Testnet. The roadmap starts from that working infrastructure, not from a mockup.
